A/T Interlock System - Shift Lock Release, Release Spring, Release Extension Replacement
NOTE: This replacement applies for the RHD model.
  1. Remove the shift lever.
  1. Remove the A/T gear position indicator panel from the shift lever.
  1. Release the lock (A) of the shift lock release extension, and remove the shift lock release extension (B).
  1. Push the stop lever (C) of the shift lock release, and remove the shift lock release (D).
  1. Remove the shift lock release spring (A) from the release (B).
  1. Replace the shift lock release, release spring, or release extension.
  1. Install the shift lock release spring in the shift lock release.
  1. Install the shift lock release (A) while aligning the tab (B) with the tab slot (C), while hooking the release spring end (D) in the slot (E), and set the stop lever (F) on the stop (G).
  1. Install the shift lock release extension (H).
  1. Install the A/T gear position indicator panel on the shift lever.
  1. Install the shift lever.
