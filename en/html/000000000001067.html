A/T Interlock System - Shift Lock Release, Release Spring, Release Shaft Replacement
NOTE: This replacement applies for the LHD model.
  1. Remove the shift lever.
  1. Remove the A/T gear position indicator panel from the shift lever.
  1. Release the lock (A) of the shift lock release, and remove the shift lock release and release spring (B).
  1. Release the lock (C) of the shift lock release shaft, and remove the shaft (D).
  1. Replace the shift lock release, release spring, or release shaft.
  1. Install the shift lock release spring (A) in the shift lock release (B).
  1. Install the shift lock release shaft (C) in the shift lever, and install the shift lock release and release spring on the release shaft end.
  1. Make sure that the release spring end (A) is installed in the shift lock release (B), and the hooked end (C) is hitched on the catch (D).
  1. Install the A/T gear position indicator panel on the shift lever.
  1. Install the shift lever.
