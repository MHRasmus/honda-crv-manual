M/T Assembly Installation
  1. Loosen the upper torque rod mounting bolt (A).
  1. Check that the two dowel pins are installed in the clutch housing.
  1. Apply urea grease UM264 (P/N 41211-PY5-305) to the release fork (A) and the release bearing (B). Install the release fork and the release bearing.
  1. Place the transmission on the transmission jack, and raise it to the engine level.
  1. Push the transmission towards engine until mainshaft engages with the spline of pressure plate.
  1. Install the lower transmission mounting bolts.
  1. Install the intercooler pipe (A), then install the intercooler pipe bracket (B).
  1. Install the intermediate shaft (A).
  1. Insert the inboard end (A) of the driveshaft into the differential (B) or intermediate shaft (C) until the set ring (D) locks in the groove (E).
  1. Support the subframe with a 4 x 4 x 40 in. Piece of wood and a jack as shown.
  1. Install the front suspension subframe (A), then connect the exhaust pipe mounting rubber (B) on the front suspension subframe.
  1. Install the lower torque rod mounting bolt and nut.
  1. Connect the front suspension stroke sensor connecter (A) (with HID).
  1. Install the steering line bracket (A) and the clips (B) on the front suspension subframe (C).
  1. Install the steering mount bracket bolts (A) and the stabilizer bush holder (B) on the front subframe (C).
  1. Connect the lower arm.
  1. Install the propeller shaft.
  1. Lower the vehicle, and make sure it is securely supported.
  1. Install the stud bolts (A).
  1. Install the transmission mount bolt (A), nuts (B) and the ground cable bolt(C).
  1. Raise the vehicle, and make sure it is securely supported.
  1. Loosen and retighten the lower torque rod mounting bolt.
  1. Install the engine under cover.
  1. Lower the vehicle, and make sure it is securely supported.
  1. Tighten the upper torque rod mounting bolt.
  1. Install the harness bracket (A) and transmission upper mounting bolts (B), then connect the harness clip (C).
  1. Remove the chain hoist (A) and engine hanger (B).
  1. Install the bolt (C) securing the fuel feed line, and install two bolts (D) securing the fuel return line, then connect the harness holder clips (E).
  1. Install the engine cover.
  1. Apply a light coat of urea grease UM264 (P/N 41211-PY5-305) to the cable ends (A) and coat the surface of the wire end rubber (B) with silicone grease.
  1. Install the cable bracket (C) and the cables (D), then install the new lock pins (E).
  1. Install the air cleaner housing stay A.
  1. Apply urea grease UM264 (P/N 41211-PY5-305) to the end of the cylinder rod. Install the slave cylinder. Be careful not to bend the clutch line.
  1. Connect the back-up light switch connector (A), countershaft speed sensor connector (B) and reverse lockout solenoid connector (C).
  1. Install the clutch line bracket (A) and battery base bracket (B).
  1. Install the hose clamp (A).
  1. Install the resonator chamber (A).
  1. Install the battery base (A) and the harness clips (B).
  1. Install the air cleaner housing.
  1. Install the battery. Connect the positive (+) cable first, then the negative (−) cable to the battery.
  1. Refill the transmission fluid.
  1. Shift into the 6th gear. Make sure the transmission does not shift direct into the reverse gear. (Then return to Neutral position, and enable to shift into reverse gear.)
  1. Check the front wheel alignment.
  1. Enter the anti-theft codes for the radio and navigation system, then enter the customer's radio station presets.
  1. Do the power window control unit reset procedure.
  1. Do the headlight learning procedure (with HID).
  1. Test-drive the vehicle.
