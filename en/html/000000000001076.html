Transfer Assembly Installation
  1. Clean the areas where the transfer assembly contacts the transmission with solvent, and dry with compressed air. Then apply transmission fluid to the contact area.
  1. Install the new O-ring (A) on the transfer assembly (B).
  1. Install the dowel pin (C) in the transmission.
  1. Install the one bolt (D) part-way in the rear lower of the transfer housing, and install the transfer assembly on the transmission.
  1. Install the propeller shaft (A) to the transfer companion flange (B) by aligning the reference mark (C).
  1. For K24Z1 engine model: Install the three-way catalytic converter (A) with the bolts, the new self-locking nuts, and new gaskets (B) (C).
    NOTE: Steps 6 thru 8 describe three-way catalytic converter installation for K24Z1 engine model, go to step 9 and install exhaust pipe A for R20A1 and R20A2 engine models.
  1. For K24Z1 engine model: Connect the A/F sensor connector and the secondary heated oxygen sensor connector.
  1. For K24Z1 engine model: Install the sensor harnesses in the harness clamps.
  1. For R20A1 and R20A2 engine models: Install exhaust pipe A with the bolts, the new self-locking nuts, and new gaskets (B) (C).
  1. Refill the transmission with ATF.
