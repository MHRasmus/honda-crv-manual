M/T Assembly Installation
  1. Loosen the upper torque rod mounting bolt (A).
  1. Check the two dowel pins are installed in the clutch housing.
  1. Apply urea grease UM264 (P/N 41211-PY5-305) to the release fork (A) and the release bearing (B). Install the release fork and the release bearing.
  1. Place the transmission on the transmission jack, and raise it to the engine level.
  1. Install the lower transmission mounting bolts.
  1. Install the clutch cover (A).
  1. Install the intermediate shaft.
  1. Install the lower torque rod mounting bracket (A).
  1. Install the inboard end (A) of the driveshaft into the differential (B) or intermediate shaft (C) until the set ring (D) locks in the groove (E).
  1. Support the subframe with a 4 x 4 x 40 in. piece of wood and a jack.
  1. Install the front suspension subframe (A).
  1. Connect the front suspension stroke sensor connector (A) (with HID).
  1. Install the lower torque rod mounting bolts (A) on the lower torque rod mounting bracket (B).
  1. Install the steering mount bracket bolts (A) and the stabilizer bust holder (B) on the front subframe (C).
  1. Connect the lower arm.
  1. Install the propeller shaft (4WD model).
  1. Install the transmission mount bracket, (A) and connect the ground cable (B).
  1. Loosen and retighten the lower torque rod mounting bolt.
  1. Install the splash shield.
  1. Tighten the upper torque rod mounting bolt.
  1. Install the engine control module (ECM) bracket (A).
  1. Install the two transmission upper mounting bolts.
  1. Remove the chain hoist and engine hanger (A) from the engine.
  1. Install the harness holder bracket (B), then install the breather pipe (C) and the harness holder (D).
  1. Connect the back-up light switch connector (A), the vehicle speed sensor connector (B), then install the harness clip (C) and the bolts (D).
  1. Connect the revers lockout solenoid connector (A), and harness clips (B).
  1. Apply a light coat of urea grease UM264 (P/N 41211-PY5-305) to the cable ends (A), and coat the surface of the wire end rubber (B) with silicone grease.
  1. Install the cable bracket (C) and the cables (D), then install the new lock pins (E) then install the harness clip (F).
  1. Apply urea grease UM264 (P/N 41211-PY5-305) to the end of the cylinder rod. Install the slave cylinder (A) and the clutch line bracket (B). Take care not to bend the clutch line.
  1. Install the battery base bracket (A), harness clip (B) and the clutch line bracket (C). Connect the ground cable (D).
  1. Install the resonator chamber (A).
  1. Install the battery base (A), harness clip (B) and the engine coolant reservoir (C).
  1. Install the air cleaner housing.
  1. Install the battery. Connect the positive cable to the battery first, then connect the negative cable.
  1. Refill the transmission fluid.
  1. Check the clutch operation.
  1. Test-drive the vehicle.
  1. Check the front wheel alignment.
  1. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
  1. Do the power window control unit reset procedure.
