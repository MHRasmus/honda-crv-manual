Power Window Master Switch Test - With Driver's Window AUTO UP/AUTO DOWN Function
With Driver's AUTO UP/AUTO DOWN Function
NOTE: For the models with the front windows AUTO UP/AUTO DOWN function, the master switch combined with the control unit so you cannot isolate the switch to test it. Instead, run the master switch input test procedures.
  1. Remove the power window master switch.
  1. Disconnect the 22P connector (A) from the power window master switch (B).
  1. Check for continuity between the terminals in each position according to the tables.
Driver's Switch
The drivers switch is combined with the control unit so you cannot isolate the switch to test it. Instead, run the master switch input test procedures. If the tests are normal, the driver's switch must be faulty; replace the power window master switch.
  1. If the continuity is not as specified, replace the switch.
