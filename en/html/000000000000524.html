System Check
NOTE: The HDS can be used to check the state of the immobilizer key registration, the ECM/PCM registration, and the communication between the ignition key and the immobilizer-keyless control unit by doing a SYSTEM CHECK.
  1. Connect the HDS to the data link connector, then turn the ignition switch ON (II).
    NOTE: If the HDS does not communicate with the vehicle, go to the DLC circuit troubleshooting.
    • 2.0 L
    • 2.4 L
  1. Select ‘‘IMMOBILIZER'' from the ‘‘SYSTEM SELECTION MENU'', the enter the ‘‘IMMOBILIZER SETUP''.
  1. Do the ‘‘SYSTEM CHECK''. If there is system check number, do the troubleshooting for the item indicated.
