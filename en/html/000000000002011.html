A/T Assembly Installation
Special Tools Required

Engine support hanger
 AAR-T1256-J00
This special tool is available from Snap-on Tools International, LLC.
NOTE: Use fender covers to avoid damaging painted surfaces.
K24Z1 Engine Model
  1. For 4WD model: Remove the propeller shaft protector.
  1. Install the torque converter (A) on the mainshaft (B) with the new O-ring (C).
  1. Install the 14 x 20 mm dowel pins (D) in the torque converter housing.
  1. Place the transmission on the jack, and raise the transmission to the engine level.
  1. Install the rear transmission housing mounting bolts.
  1. Install the front transmission housing mounting bolts.
  1. Install the upper transmission housing mounting bolts.
  1. Secure the transmission mount bracket on the transmission housing with the new mounting bolts.
  1. Install the new set ring (A) on the intermediate shaft (B).
  1. Clean the areas where the intermediate shaft contacts the transmission (differential) with solvent, and dry with compressed air. Apply intermediate shaft splines (C) with ATF, then install the intermediate shaft, be sure not to allow dust or other foreign particles to enter the transmission.
  1. Install the new set ring (A) on the left driveshaft (B).
  1. Clean the areas where the left driveshaft contacts the transmission (differential) with solvent, and dry with compressed air. Then install the left driveshaft, be sure not to allow dust or other foreign particles to enter the transmission. Turn the steering knuckle fully outward, and slide the driveshaft into the differential until you feel its set ring fully engage the side gear.
  1. Apply right driveshaft inboard-joint splines with the recommended grease.
  1. Slide the right driveshaft over the intermediate shaft splines until you feel the driveshaft fully engage the intermediate shaft set ring.
  1. Attach the torque converter to the drive plate with eight bolts (A). Rotate the crankshaft pulley as necessary to tighten the bolts to 1/2 of the specified torque, then to the final torque, in a crisscross pattern. After tightening the last bolt, check that the crankshaft rotate freely.
  1. Install the torque converter cover (B).
  1. Support the front subframe with a wood piece and a jack, and lift it up to the body.
  1. Loosely install the new subframe mounting bolts.
  1. Align all reference marks (A) on the front subframe (B) with the body, then tighten the mounting bolts on the subframe to the specified torque.
  1. Install both mid-bracket bolts with new ones.
  1. Secure the lower torque rod with the new bolts.
  1. For 4WD model: Install the propeller shaft protector.
  1. For 4WD model: Install the propeller shaft (A) to the transfer companion flange (B) by aligning the reference mark (C).
  1. Loosely install the steering gearbox bracket mounting bolts.
    NOTE: The illustration shows the LHD model; RHD is similar.
  1. Loosely install the steering gearbox bracket mounting bolts.
    NOTE: The illustration shows the LHD model; RHD is similar.
  1. Tighten the steering gearbox bracket mounting bolts to the specified torque.
  1. Install both lower arms (A) to both ball joints (B), and loosely install the new mounting nuts and bolts.
  1. Tighten the nuts and bolts to 59 N·m (6.0 kgf·m, 43 lbf·ft) in the following order; the nut on the front (C), the nut on the rear (D), then the bolt (E).
  1. Install the stabilizer links (F) to the stabilizer, and install the nuts (G). Insert a 6 mm Allen wrench (H) in the ball joint pin (I), and tighten the nuts.
  1. Install the three-way catalytic converter (A) with the bolts, the new self-locking nuts, and new gaskets (B) (C).
  1. Connect the A/F sensor connector and the secondary heated oxygen sensor connector.
  1. Install the sensor harnesses in the harness clamps.
  1. Install the shift cable holder bracket on the transmission.
  1. Apply molybdenum grease to the bore hole of the synthetic resin bushing (A) in the shift cable end (B), and attach the shift cable end to the control lever (C). Insert the control pin (D) into the control lever hole through the shift cable end, and secure the control pin with the spring clip (E). Do not bend the shift cable excessively.
  1. Secure the shift cable brackets (F) (G) with the bolts.
  1. Install the shift cable cover (H).
  1. Secure the ATF filter with the bolt on the front subframe.
  1. Secure the power steering fluid line clamp (A) with the bolt.
  1. Secure the power steering fluid line (B) with the clamps (C).
  1. Remove the hanger plate (A) and bolt (B), and install the air cleaner housing mounting bracket (C) on the engine.
  1. Remove the engine support hanger.
  1. Connect the ATF cooler hoses (A) to the ATF cooler lines (B), and secure the hoses with the clips (C).
  1. Connect the shift solenoid harness connector (A), A/T clutch pressure control solenoid valve C connector (B), and A/T clutch pressure control solenoid valve B connector (C), and install the harness clamp (D) on the clamp bracket (E).
  1. Connect the 3rd clutch transmission fluid pressure switch connector (A), and install the harness clamp (B) on its clamp bracket (C).
  1. Connect the output shaft (countershaft) speed sensor connector (A) and input shaft (mainshaft) speed sensor connector (B), and install the harness clamp (C) on its clamp bracket (D).
  1. Install the transmission range switch connector (E) on the connector bracket, and connect the connector.
  1. Connect the A/T clutch pressure control solenoid valve A connector (A) and 2nd clutch transmission fluid pressure switch connector (B), and install the harness clamps (C) on the clamp brackets (D).
  1. Install the air cleaner housing mounting bracket, and install the harness clamp on the harness clamp bracket.
  1. Refill the transmission with ATF.
  1. Install the battery base.
  1. Install the air cleaner housing and intake air duct.
  1. Install the bulkhead cover.
  1. Install the cowl cover.
  1. Install the windshield wiper arms.
  1. Install the battery tray, battery, and battery cover, then secure the battery with its hold-down bracket.
  1. Connect the battery terminals, and apply grease around the battery terminals.
  1. Set the parking brake. Start the engine, and shift the transmission through all positions three times.
  1. Check the shift lever operation, A/T gear position indicator operation, and shift cable adjustment.
  1. Check and adjust the front wheel alignment.
  1. Install the splash shield.
  1. Start the engine in the P or N position, and warm it up to normal operating temperature (the radiator fan comes on). Turn off the engine, and check the ATF level.
  1. Enter the radio (and navigation) anti-theft code if epuipped, then enter the radio presets, and set the clock.
  1. Do the power window control unit reset procedure.
  1. Perform the road test.
  1. After the road test, raise the vehicle on a hoist, and make sure it is securely supported.
  1. Loosen the upper torque rod bolt (A).
  1. Loosen the transmission mount base bracket bolt (A) and nuts (B).
  1. Loosen the lower torque rod bolts (A) (B).
  1. Retighten the lower torque rod bolts (B) to the specified torque, then retighten the bolt (A) to the specified torque.
  1. Tighten the transmission mount base bracket bolt and nuts to the specified torque.
  1. Tighten the upper torque rod bolt to the specified torque.
