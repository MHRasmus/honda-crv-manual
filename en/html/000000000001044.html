A/T 1st, 2nd, and 3rd Clutch Reassembly
  1. Soak the clutch discs thoroughly in ATF for a minimum of 30 minutes.
  1. For K24Z1 engine model 1st clutch: Install the waved spring (A) in the 1st clutch drum (B). Install the clutch flat-plate (C) (1), then starting with the clutch disc, alternately install the discs (D) (5) and waved-plates (E) (4). Install the clutch-end-plate (F) with the flat side down on the top disc.
  1. For K24Z1 engine model 2nd clutch: Install the waved spring (A) in the 2nd clutch drum (B). Install the clutch flat-plate (C) (1), then starting with the clutch disc, alternately install the discs (D) (6) and waved-plates (E) (5). Install the clutch-end-plate (F) with the flat side down on the top disc.
  1. For K24Z1 engine model 3rd clutch: Install the waved spring (A) in the 3rd clutch drum (B). Install the clutch flat-plate (C) (1), then starting with the clutch disc, alternately install the discs (D) (6) and waved-plates (E) (5). Install the clutch-end-plate (F) with the flat side down on the top disc.
  1. For R20A1 and R20A2 engine models 1st clutch: Install the waved spring (A) in the 1st clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch waved-plates (C) (5) and discs (D) (5), then install the clutch-end-plate (E) with the flat side down on the top disc.
  1. For R20A1 and R20A2 engine models 2nd clutch: Install the waved spring (A) in the 2nd clutch drum (B). Install the 4.0 mm-thick plate (C) with the shear droop side (D) toward the inside of the drum, clutch disc (E), and 2.0 mm-thick flat-plate (F). Starting with the clutch disc, alternately install the discs (G) (4) and waved-plates (H) (3), then install the clutch-end-plate (I) with the flat side down on the top disc.
  1. For R20A1 and R20A2 engine models 3rd clutch: Install the waved spring (A) in the 3rd clutch drum (B). Install the clutch flat-plate (C), clutch disc (D), and clutch flat-plate (E). Starting with the clutch disc, alternately install the discs (F) (4) and waved-plates (G) (3), then install the clutch-end-plate (H) with the flat side down on the top disc.
  1. Install the snap ring with a screwdriver to secure the clutch-end-plate.
  1. Check that the clutch piston moves by applying air pressure into fluid passage.
