Power Window Front Passenger's Switch Test - With Driver's Window AUTO UP/AUTO DOWN Function
With Driver's AUTO UP/AUTO DOWN Function
NOTE: For the models with the front windows AUTO UP/AUTO DOWN function, each window switch is combined with the control unit so you cannot isolate the switch to test it.
Instead, run the front passenger's power window switch input test, or the rear power window switch input test.
  1. Remove the passenger's power window switch.
  1. Disconnect the 8P connector (A) from the passenger's power window switch (B).
    NOTE: The illustration shows the front passenger's switch.
With Driver's AUTO UP/AUTO DOWN Function
NOTE: For the models with the front windows AUTO UP/AUTO DOWN function, each window switch is combined with the control unit so you cannot isolate the switch to test it.
Instead, run the front passenger's power window switch input test, or the rear power window switch input test.
  1. Remove the passenger's power window switch.
  1. Disconnect the 8P connector (A) from the passenger's power window switch (B).
    NOTE: The illustration shows the front passenger's switch.
  1. Check for continuity between the terminals in each position according to the tables.
  1. Connect battery power to the No. 4 terminal and ground the No. 7 (or No. 8) terminal. The switch light should come on.
  1. If the continuity is not as specified, replace the switch.
