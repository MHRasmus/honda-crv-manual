Rear Differential Installation
  1. Install rear differential mount assembly A to the rear differential assembly (B).
  1. Jack up the rear differential.
  1. Install the new set rings (A) onto the driveshafts, then insert the driveshafts into the rear differential.
  1. Lift the rear differential up into position, then push on both driveshafts to lock the set rings into place. Connect the breather tube (B).
  1. Align the tab (A) of the rubber mount (B) with the hole (C) of the plates (D), then install the plates and torque the rear differential mount assembly mounting bolts (E).
    NOTE: The rubber heat insulator (F) is installed only in the right side.
  1. Install the breather tubes (G) to the clips (H).
  1. Install the right and left rear differential mount brackets B (A), then torque the bolts (B).
  1. Install the breather tube (C) to the clip (D).
  1. Install the No. 2 propeller shaft (A) onto the rear differential (B) by aligning the reference marks (C) made during removal. Make sure you use new mounting bolts (D).
  1. Fill the rear differential with the differential fluid to the proper level.
