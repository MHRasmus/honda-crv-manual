Starter Removal and Installation
Removal
  1. Make sure you have the anti-theft code for the audio system and the navigation system (if equipped).
  1. Disconnect the negative cable from the battery, then disconnect the positive cable.
  1. Remove the splash shield.
M/T
A/T
  1. Remove the intake manifold bracket.
  1. Remove the harness clamp (A), and remove the two bolts (B) securing the starter, then remove the starter from the engine.
Except KQ model
KQ model
  1. Disconnect the starter cable (A) from the B terminal, then disconnect the BLK/WHT wire (B) from the S terminal.
  1. Remove the harness clamp (C), then remove the starter.
Except KQ model
KQ model
Installation
  1. Install the starter cable (A) and BLK/WHT (B) wire. Make sure the starter cable crimped side of the ring terminal is facing out.
  1. Install the harness clamp (C).
Except KQ model
KQ model
  1. Install the starter, tighten the bolts, then install the harness clamp (A).
Except KQ model
KQ model
  1. Install the intake manifold bracket.
  1. Install the splash shield.
  1. Connect the positive cable to the battery first, then connect the negative cable.
  1. Start the engine to make sure the starter works properly.
  1. Enter the anti-theft code for the audio system and navigation system (if equipped).
  1. Set the clock.
