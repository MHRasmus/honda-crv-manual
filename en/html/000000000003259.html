DTC Troubleshooting: P145C (90)
DTC P145C:
 EVAP System Purge Flow (Vacuum Line)
NOTE:
  • Before you troubleshoot, record all freeze data and any on-board snapshot, and review the general troubleshooting information.
  • This DTC is ploblem representative of an EVAP system purge flow. If DTC P145C is indicated alone, troubleshoot P0496 and P0497 using the freeze data for P145C.
  • If any of the DTCs listed below are indicated at the same time as DTC P145C troubleshoot those DTC first, then recheck for P145C:
    P0496, P0497: EVAP system purge flow
