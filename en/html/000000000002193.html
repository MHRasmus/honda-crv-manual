Intercooler Replacement
  1. Remove the engine undercover.
  1. Remove the front bumper.
  1. Remove the clips (A) securing the front inner fender, then remove the inter cooler intake hose (B).
  1. Remove the duct.
  1. Remove the intercooler lower bracket (A) and intercooler upper bracket (B).
  1. Remove the intercooler outlet hose (A), then remove the intercooler (B).
  1. Remove the intercooler intake pipe (A).
  1. Install the intercooler intake pipe with new gasket (B).
  1. Install the intercooler (A) to the intercooler outlet hose with the mark (B) on the intercooler aligned with the mark (C) on the outlet hose.
  1. Install the intercooler upper bracket (A) and intercooler lower bracket (B). Make sure the upper and lower cushions are set securely.
  1. Install the duct.
  1. Install the intercooler intake hose (A), then install the clips (B) securing the front inner fender.
  1. Install the front bumper.
  1. Install the engine undercover.
